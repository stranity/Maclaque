2. Produit

Maclaque est une application macOS qui détecte les impacts physiques sur le châssis d'un MacBook Apple Silicon et joue des sons en réponse. Le Produit est livré sous forme de fichier téléchargeable (.dmg).

Configuration requise :

  • • MacBook avec puce Apple Silicon (M1, M2, M3, M4 ou variantes)
  • • macOS 13 (Ventura) ou version ultérieure
