Politique de confidentialité

Dernière mise à jour : 17 juin 2026

Maclaque est conçu avec le respect de votre vie privée comme priorité. Cette politique explique quelles données sont collectées, pourquoi, et comment les exercer vos droits.

1. Responsable du traitement

Melvyn Beherec, entrepreneur individuel
Email : contact@maclaque.shop

2. Données collectées

a) Sur le site maclaque.shop

Le site ne dépose aucun cookie de tracking et n'utilise aucun outil d'analytics. Lors de l'achat, vous êtes redirigé vers Stripe qui collecte les informations nécessaires au paiement (email, données bancaires). Ces données sont traitées par Stripe selon leur propre politique de confidentialité.

b) Dans l'application Maclaque

Donnée Finalité Stockage
Identifiant appareil (UUID aléatoire) Limiter l'abus de la génération de sons IA Local (UserDefaults) + transmis au proxy lors de la génération
Préférences utilisateur (volume, pack, etc.) Sauvegarder vos réglages Local uniquement (UserDefaults)
Texte saisi pour la génération de sons Générer les fichiers audio via ElevenLabs Transmis au proxy, non conservé après génération

L'application ne collecte aucune donnée d'analytics, de crash, de localisation ou de comportement. Aucune donnée n'est envoyée à des tiers à l'exception du service de synthèse vocale (ElevenLabs, via un proxy Cloudflare Workers) utilisé uniquement lors de la création de sons personnalisés.

3. Base légale

Le traitement des données repose sur l'exécution du contrat (article 6.1.b du RGPD) : les données sont nécessaires pour fournir le service acheté (génération de sons custom).

4. Transferts hors UE

Le proxy de génération de sons est hébergé par Cloudflare (USA). Les données de paiement sont traitées par Stripe (USA). Ces transferts sont encadrés par le EU-US Data Privacy Framework.

5. Durée de conservation

Les données locales (préférences, UUID) persistent tant que l'application est installée. La désinstallation supprime toutes les données locales. Les textes envoyés pour génération ne sont pas conservés après traitement.

6. Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données, vous disposez des droits suivants :

  • • Accès — obtenir une copie de vos données
  • • Rectification — corriger des données inexactes
  • • Effacement — demander la suppression de vos données
  • • Portabilité — recevoir vos données dans un format structuré
  • • Opposition — vous opposer au traitement

Pour exercer ces droits, contactez-nous à contact@maclaque.shop. Nous répondons sous 30 jours maximum.

En cas de réclamation, vous pouvez saisir la CNIL : www.cnil.fr.

7. Modifications

Cette politique peut être mise à jour. La date de dernière modification est indiquée en haut de page.
